# Excel Workbook Automation Using VBA

## Project Overview
This project focuses on automating repetitive Excel workbook operations using VBA (Visual Basic for Applications). It simplifies workbook management by automating worksheet indexing, individual workbook creation, and PDF generation.

The primary objective is to reduce manual effort, improve accuracy, and increase productivity through Excel VBA automation.

## Technologies Used
- Microsoft Excel
- Visual Basic for Applications (VBA)
- Excel Object Model

## Project Modules

### 1. Automatic Index Sheet Generator
- Automatically creates an index sheet.
- Lists all worksheet names with clickable hyperlinks.
- Calculates the number of used rows and columns in each worksheet.
- Handles blank worksheets by leaving row and column counts empty.

### 2. Individual Workbook Generator
- Exports each worksheet into a separate Excel workbook.
- Automatically uses worksheet names as output filenames.
- Allows users to select a destination folder.
- Preserves worksheet data and formatting.

### 3. PDF Generation Automation
- Exports individual worksheets or the entire workbook into PDF format.
- Automatically generates PDF filenames.
- Allows users to select the output folder.
- Uses Excel's ExportAsFixedFormat functionality.
- Maintains print layout and page formatting.
